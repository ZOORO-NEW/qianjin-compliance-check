# 全量违规词库

> 每个词条标注：级别 / 法条依据 / 合规替换方向
> 级别：🔴高危（法律明确禁止或行业禁投）🟡中危（平台封控）🟢低危（语境敏感）

## 一、极限绝对化用语类

> **2026新规提示**：天花板、绝了、绝绝子在**营销/带货语境**下已纳入封控。非商业闲聊偶尔出现管控宽松，但任何推广内容中一律不用。

### 1.7 可放行场景（重要）
以下情形**不构成违规**（执法指南第五、六条）：

| 场景 | 示例 | 是否合规 |
|---|---|---|
| 个人主观感受 | "这是我用过最顺手的" | ✅ 通常合规 |
| 经营理念/目标追求 | "我们致力于做行业最好的服务" | ✅ 合规 |
| 同品牌自我比较 | "比XX上一代提升30%" | ✅ 合规（需可证明） |
| 消费提示 | "最佳保存方式：阴凉干燥处" | ✅ 合规 |
| 国标分级用语 | "一级建造师"（有依据） | ✅ 合规 |
| 商标/专利名称含该词 | "第一夫人"系列商标 | ✅ 合规 |
| 官方奖项称号 | "国家级非物质文化遗产" | ✅ 合规 |
| 限定时间地域的事实 | "2025年该品类销量第一（数据来源：XX）" | ✅ 合规（需标出处） |

## 三、医疗功效类（高危，按行业区分）

**依据**：《广告法》第十六条、第十七条、第十八条；食品安全法第七十三条

### 3.1 疾病治疗功能（任何非医疗类广告全部禁用）🔴
治疗、治愈、根治、痊愈、疗效、药到病除、去除病灶、消炎、杀菌、
抗菌、抑菌、除菌、杀灭病毒、预防疾病、抗癌、防癌、抑制肿瘤、
杀死癌细胞、抗病毒、消炎止痒、止痛、止咳、化痰、退烧、
降血糖、降血压、降血脂、降三高、降尿酸、修复受损肌理、
疏通血管、软化血管、排毒、祛湿、 detox、
清除宿便、调理肠胃（需谨慎）、治本、斩草除根

### 3.2 养生类（易被判变相发布）🔴
延年益寿、长寿因子、抗衰老、逆龄、年轻十岁、排毒养颜、
调理体质、改善体质、增强免疫力、提高免疫力、增强抵抗力、
补气、养血、滋阴、壮阳、补肾、抗疲劳、缓解疲劳、改善睡眠、
助眠、安神、提高睡眠质量

### 3.3 化妆品医疗暗示 🔴（条例第三十七条 + 标签办法第十九条）
消炎、杀菌、抑菌、修复、治愈、祛痘（治疗义）、祛斑（治疗义）、
修复屏障、抗敏（治疗义）、祛湿、排毒、养肤（医疗义）、
"药妆""医学护肤品""医美级""院线同款""医用敷料平替"、
修复受损肌理、溶解死细胞、燃脂、燃烧脂肪

> **标签办法第十九条第一项**：使用医疗术语、医学名人姓名、描述医疗作用效果的词语或已批准药品名，明示或暗示医疗作用。

### 3.4 可放行（持证产品）
- **特殊化妆品**（染发、烫发、祛斑美白、防晒、防脱发、宣称新功效）：须有特殊化妆品注册证，可按注册证核准功效表述
- **医疗器械**：须有医疗器械广告审查批准文号，可按审查通过内容发布，仍不得含治愈率有效率
- **保健食品**：可表述注册证书内的保健功能，但**不得涉及疾病预防治疗**

## 六、虚假对比与贬低同行类

**依据**：《广告法》第十三条 + 《化妆品标签管理办法》第十九条第五项

🔴 别家不行、只有我们好、其他品牌都垃圾、行业最差、
碾压同行、吊打同类、秒杀同级、完爆大牌、吊打竞品、
秒杀竞品、全网对比（点名）、友商塌房、
没有对比就没有伤害（指向同行）

**合规做法**：可以对比**参数**（"我们用的是XX材质，某品牌用的是YY"），不点名、不贬低。

**化妆品特别禁止**：通过编造虚假信息、**贬低其他合法产品**等方式误导消费者（标签办法第十九条第五项）。

## 十三、变体与谐音规避手法（必须识别并告知无效）

| 规避手法 | 示例 | 平台识别能力 |
|---|---|---|
| 拼音替换 | zui好、niubei、666 | 可识别 |
| 数字符号替换 | ①号好物、N0.1、TOP1、第① | 可识别 |
| 形近字替换 | 最→最（异体）、假→暇 | 可识别 |
| 繁简切换 | 最優、專供 | 可识别 |
| 全半角混用 | ＮＩＮＥ、１００％ | 可识别 |
| 拆字 | 最好的 → 分开写 | 可识别 |
| 谐音 | 嘴好用、治（纸）疗 | 可识别 |
| 图片内嵌 | OCR抓取标题/封面/详情页/水印 | 可识别 |
| 直播口播 | ASR实时转写，说错当场断播 | 可识别 |
| 拼音首字母 | zhyh（最好用） | 语义模型识别 |

**OCR检测范围**：标题、正文、封面大字、图片水印、详情页小字、
贴纸、弹幕、直播背景文案、字幕。

**处理原则**：直接告知"这样写一样会被判违规"，并给出真正可用的替代方案。
不要给"如何规避审核"的方案。

## 十四、低危语境敏感词（不必然违规）

以下是**高危词中的安全用法**，判定时不要误报：

| 词 | 违规用法 | 合规用法 |
|---|---|---|
| 第一 | 全网第一、销量第一 | 第一次尝试、第一时间、第一手资料 |
| 顶级 | 顶级工艺 | 一线品牌（非顶级） |
| 独家 | 独家配方 | 我自己摸索出来的方法（陈述个人行为） |
| 权威 | 权威机构认证（虚构） | 据XX机构发布的报告 |
| 天然 | 纯天然无副作用 | 配料表未添加XX（以实物标签为准） |
| 永久 | 永久有效 | 长期使用体验（客观陈述） |
| 最 | 全网最好 | 我自己最常用的（个人体验） |
| 治愈 | 治愈失眠 | 缓解日常疲劳感（不作疾病表述） |
