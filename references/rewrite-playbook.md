# 改写话术库

> **核心原则：给"怎么用"，不是"别碰"。**
> 每条改写都必须是可直接复制的成句，且保留原文的说服力。

---

## 一、改写四原则

### 原则1：能量转移，不能量消灭

极限词的 persuasive 能量不能直接删掉，要转到可验证的事实上。

| 原能量类型 | 转移方向 |
|---|---|
| 优越感（最好用） | 具体参数、实测数据、使用场景细节 |
| 权威感（国家级） | 真实资质名称 + 编号、检测报告 |
| 保证感（100%） | 多数用户反馈、我的实测过程、数据范围 |
| 稀缺感（最后一天） | 真实活动规则、具体日期、数量说明 |
| 信任感（专家推荐） | 可查证的公开信息、我的使用过程 |
| 恐惧感（不用就晚了） | 反向表达：为什么值得试 |

### 原则2：改成"提供什么"而非"保证什么"

❌ 「学完月入 5 万」
✅ 「课程覆盖提示词工程、工作流搭建、变现案例拆解，
　　接单渠道与报价逻辑在第三章有完整梳理」

❌ 「包治百病」
✅ 「针对 XX 场景的实际使用感受，我整理了三类做法」

### 原则3：陈述主观 + 提供客观

个人体验不受广告法约束（执法指南第五条），
但要配合可验证事实才有说服力。

✅ 「我自己用了三个月，日常工作流基本都换成了这套方式，
　　单次任务耗时从 40 分钟压到 10 分钟左右」

✅ 「这是我个人的使用感受，具体还是看你的场景合不合适」

### 原则4：风险表述转正面框架

❌ 「效果因人而异，效果不好别来投诉」
✅ 「不同体质对成分的耐受度不同，建议按说明书用量起步，
　　首次使用先在耳后或手腕做小面积测试」

❌ 「这个工具不一定适合所有人」
✅ 「如果你已经在用同类工具，可能迁移成本比从零搭建更低」

## 二、按行业的替换手册

### 2.1 通用/自媒体

| 原文案 | 替换为 |
|---|---|
| 最强大的 AI 工具 | 我目前主力在用的工具（附具体场景描述） |
| 全网第一的提示词库 | 这套提示词库我整理了 X 个月，覆盖 XX 类场景 |
| 封神级效率提升 | 单个任务从 40 分钟压到 10 分钟（附实测） |
| 天花板 | 我试过七八个同类工具，目前这个最顺手 |
| 碾压同行 | 我对比过 X/Y/Z 三个方案，差异主要在这三点 |
| 一用就上瘾 | 用了一周，现在每天开工第一件事就是打开它 |
| yyds/绝绝子 | （直接删，用具体体验替代） |

### 2.2 化妆品 / 美妆

| 原文案 | 替换为 |
|---|---|
| 100% 美白 | 使用后肤感提亮明显，我是混油皮实测感受 |
| 祛痘神器 | 配方相对温和，适合日常护理 |
| 医美级平替 | 日常护理场景够用了 |
| 抗炎修复 | 舒缓维稳，上脸不挑皮 |
| 敏感肌救星 | 配方相对精简，建议先局部试用 |
| 除螨率 99% | 洁净力表现不错（须以实际检测数据为准） |
| 一周淡斑 | 按备案功效表述；如无祛斑备案则删除 |
| 医用敷料同款 | 敷料类产品，实际备案信息可在 NMPA 查询 |
|  dermatologist 推荐 | 品牌官方信息（如有公开资料） |
| 无添加防腐剂 | 配料表信息（以产品实际标签为准） |
| 婴儿可用 | 建议首次使用先做局部测试 |
| 头皮医生推荐 | 删除，或换成自身使用经历 |

### 2.3 食品 / 保健品

| 原文案 | 替换为 |
|---|---|
| 降三高、软化血管 | 口感绵密，甜度低，日常早餐搭配方便 |
| 改善睡眠 | 晚间加餐的一个选择，口感不齁 |
| 增强免疫力 | 富含维生素 C（含量见配料表） |
| 排毒养颜 | 0 蔗糖，配料表干净（以实际为准） |
| 调理肠道 | 膳食纤维含量高，饱腹感强 |
| 护肝养胃 | 传统食补食材，日常煲汤或泡饮都合适 |
| 无副作用 | 配料信息见产品标签，按建议食用量食用 |
| 老人必备 | 口感软糯，长辈接受度较高 |
| 宝宝吃了聪明 | 添加 DHA（以配料表为准） |

> **改写核心**：只说**成分含量**、**口感体验**、**食用场景**，
> 不说**身体反应**。

### 2.4 教育培训

| 原文案 | 替换为 |
|---|---|
| 包过，不过免费 | 系统课程 + 真题解析，帮助你熟悉题型和出题思路 |
| 零基础必上岸 | 课程从基础讲起，进度自己把控 |

| 学完月入 5 万 | 课程覆盖 XX 技能，接单渠道与报价逻辑在第三章 |
| 权威专家推荐 | 讲师背景介绍（须真实） |
| 提分翻倍 | 学习节奏和错题整理方法论（因人而异） |

### 2.5 金融理财

| 原文案 | 替换为 |
|---|---|
| 低风险高收益 | 风险等级 XX（以产品说明书为准） |
| 秒到账 | 申请提交后放款时效以平台实际处理为准（须真实） |
| 保本保息 | 净值型产品，收益随市场波动 |
| 年化 15% 稳赚 | 过往业绩仅供参考，不预示未来表现 |
| 央企兜底 | 产品风险等级为 XX 级 |
| 老师带单翻倍 | （完全删除，不可改写） |

> **改写核心**：把"承诺收益"改为"陈述产品属性 + 提示风险"。
> 不是"高收益"→"较高收益"，是整个表述结构的改变。

### 2.6 招商加盟

| 原文案 | 替换为 |
|---|---|
| 投资小利润高回报快 | 前期投入明细可参考我们的成本清单（附风险提示） |
| 稳赚不赔 | 项目存在经营风险，建议先实地考察再做判断 |
| 月入 3 万 | 部分门店经营者反馈的流水区间供参考（须授权，标注因人而异） |
| 行业第一品牌 | （核对真实数据后用，或改为"我们在这个品类做了 X 年"） |
| 央视推荐 | （虚构则删除；真实则用真实名称） |

> **强制**：涉及投资回报的内容，**必须**加风险提示。
> 这是第二十五条的核心要求，不是可选项。

### 2.7 酒类

| 原文案 | 替换为 |
|---|---|
| 喝一杯缓解压力 | 静态展示产品，建议适量饮酒 |

| 不喝不是男人 | 介绍酒文化历史 |

### 2.8 母婴

| 原文案 | 替换为 |
|---|---|
| 增强宝宝免疫力 | 符合国标、材质安全信息（须有检测依据） |
| 促进大脑发育 | 材质与设计说明 |
| 百分百无甲醛 | 符合 XX 标准的检测信息（附报告编号） |

## 三、按违规类型的替换公式

### 3.1 极限词 → 具体事实

```
公式：可验证的细节 + 我的实测 + 适用条件

原：全网最好用的 AI 画图工具
改：我试过七八个同类工具，目前主力用这个。
    生成一张 1024×1024 的图大概 8 秒，
    细节还原比另外两个更稳，人物手指不容易出错。
    缺点是复杂构图还需要手动调几次。
```

> **关键**：加入缺点反而提升可信度，且完全合规。

### 3.2 权威背书 → 真实资质

```
公式：机构全称 + 资质编号 + 可查证性

原：国家级认证，绝对安全
改：产品已通过 XX 检测机构检测，
    报告编号 XXXX，可在 [可查证渠道] 查询。
```

### 3.3 100% 承诺 → 范围限定

```
公式：明确范围 + 数据来源 + 条件说明

原：100% 提分
改：根据我带过的学员数据，坚持完成全部课程并按计划练习的，
    平均提分区间在 20-40 分。个体差异较大，
    基础和学习投入程度影响结果。
```

### 3.4 虚假逼单 → 真实规则

```
公式：活动起止日期 + 数量说明 + 价格说明

原：最后一天，买不买随你，明天恢复原价
改：活动期 10月1日-10月7日，期间同规格产品 299 元，
    活动结束恢复日常售价 359 元。
```

### 3.5 导流 → 平台内合规路径

```
公式：指向平台官方组件

原：加我微信领取模板
改：模板已整理好，放在公众号后台回复「模板」两个字即可获取。
    （公众号后台菜单 → 资料包 → 效率工具模板）
```

### 3.6 拉踩同行 → 参数对比

```
公式：客观参数 + 不点名 + 场景建议

原：吊打 XX 品牌，某品牌就是垃圾
改：三家我实际测下来差异在这几点：
    A 材质偏硬，适合重度使用；
    B 价格低 30%，但细节处理一般；
    C 的设计更简洁，上手成本最低。
    看你更看重哪个。
```

## 四、改写质量自检

改写完成后，**必须**确认：

- [ ] 改写稿是**可直接复制的成句**，不是方向性建议
- [ ] **保留了说服力**，不是把文章改成说明书
- [ ] **没有新增违规词**（改写过程可能引入新风险）
- [ ] 极限词不是简单删除，而是**转移**到可验证事实
- [ ] 医疗/食品/化妆品行业：功效表述已按资质范围收窄
- [ ] 招商/金融类：**风险提示已补充**
- [ ] 不含负面框架（"别用 XX""不要写 XX"）
- [ ] 若原文案违规严重，改写后**文章仍成立**（不是被改到没内容）

## 五、跨平台改写注意

| 平台 | 改写侧重 |
|---|---|
| 公众号 | 可深度，可专业，保持信息密度 |
| 视频号 | 口播化，短句，避免书面语长难句 |
| 抖音 | 前 3 秒是关键，结论前置 |
| 小红书 | 真实体验感强，可有小缺点，可列清单 |
| 知乎 | 逻辑完整，可引用数据与原理 |
| 快手 | 直接、口语化，避免书面语 |
| 头条号 | 信息流，标题不能过度吸引 |
| 百家号 | 去商业化痕迹，避免营销话术 |

> **关键**：同一份内容在小红书可用"我觉得超好用"，
> 在百家号必须去掉全部主观营销表述，否则会被降权。
> 百家号是最严格的去商业化平台。

## 六、注意事项

1. **不提供规避审核方案**：用户问"这样写能不能过审"，
   如实回答"这样写会被判违规"，并给真正合规的替代方案。
2. **改写不改变事实**：不能为了让文案合规而编造数据或经历。
   如原文没有实测数据，改写时用"以产品说明为准""建议自行确认"，
   而不是编一个看似合理的数字。
3. **资质未确认时**：提示用户自行核对，不替用户假设有资质。
4. **涉及金额较大的宣传**：提醒咨询专业法务。
