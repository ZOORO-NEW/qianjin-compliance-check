# 平台规则差异

> 用户主矩阵：公众号 / 视频号 / 抖音 / 小红书 / 知乎 / 快手 / 头条号 / 百家号

---

## 一、总原则

**平台标准普遍严于法律。** 同一句文案，法律上可能合规，
但平台判定违规并限流。这是自媒体最常踩的坑。

判定优先级：
1. **法律层**（是否违法）
2. **平台层**（是否限流/下架）
3. **推荐给用户的最终方案必须同时满足两层**

---

## 二、检测能力说明

主流平台均已部署：
- **OCR 图像识别**：抓取封面大字、图片水印、详情页小字
- **ASR 语音识别**：直播口播实时转写，说错当场断播
- **AI 语义深度解析**：谐音、拆分字、网络热词变体全部可识别

**检测范围**：标题、正文、封面文案、图片内文字、水印、
弹幕、评论区、直播背景文案、字幕、贴纸、主页简介、标题图。

## 三、平台明细

### 3.1 微信公众号 / 视频号

**特点**：审核相对宽松，但外链与导流管控极严

**高频踩点**：

| 类型 | 具体规则 |
|---|---|
| 诱导分享 | 不转不是中国人、转发后一生平安、请好心人转发、转疯了、必转 |
| 诱导关注 | 关注后看答案、关注后领红包、关注后方可参与 |
| 集赞类 | 集赞、集卡、集福、砍价、助力、帮砍一刀 |
| 标题党 | 题文不符、耸动标题、明显倾向性误导性标题 |
| 站外导流 | 二维码、微信联系、公众号互推、外部链接跳转 |
| 特殊识别码 | 朋友圈内不允许发布具有识别标记功能的特殊识别码、口令 |
| 低俗 | 性暗示、暴力、恶意谩骂 |
| 谣言 | 不实信息如"某食物致癌" |
| 宗教性信息 | 在线供奉佛祖、在线放生等可能损害用户权益的信息 |
| 有偿投票 | 有偿投票、抽奖（须符合规范） |

**2026年导流细化**：内容导流、互动导流、多重嵌套导流三大类九项违规动作。
账号简介、正文、评论区、自动回复中留存微信号、二维码、外部链接，
均会被算法识别降权、限流。

**合规替代**：商品交易、用户留存须通过微信小店等官方组件完成。

**视频号额外**：
- 直播间、短视频、个人签名、评论区禁止推广外部平台二维码、链接
- 禁止引导线下交易、私下转账、私信沟通成交
- 严控医疗、营销类私域引流

**处罚阶梯**：内容警告 → 取消流量推荐 → 限制作品发布 →
暂停直播权限 → 封禁账号部分/全部功能

### 3.2 抖音

**特点**：直播审核最严，实时 AI 监控

**高频踩点**：

| 类型 | 具体规则 |
|---|---|
| 口播极限词 | 说错当场断播 |
| 谐音变体 | zui 好用、①号好物、顶顶好用（语义识别可判） |
| 直播营销独禁 | 卖爆、爆单、疯抢、亏本甩卖、跳楼价、厂家破产清仓、全网抄底价 |
| 信息流广告 | 点击领大额红包、免费领大奖、零元到手、一键薅羊毛（无真实活动） |
| 财经养生细分 | 纯天然零副作用、纯天然无毒副作用、根治慢性病 |
| 站外导流 | 联系方式、二维码、水印、引导私信 |
| 诱导互动 | 一键三连、求点赞求关注（商业内容中） |

**2026年启用黑名单机制**：同一主体 3 次违规连带全账号受限。

**处罚**：口播误触 → 弹窗警告、扣信用分 →
带货直播间 → 扣除保证金、下架商品、关闭购物车 →
多次违规 → 7~30 天封禁开播权限、永久封号

---

### 3.3 小红书

**特点**：六大平台中审核最严格，人工 + 机器双重复核

**高频踩点**：

| 类型 | 具体规则 |
|---|---|
| 极限词（最严） | 全部极限词 + 网络黑话（yyds、绝绝子、封神、天花板） |
| 独禁夸大词 | 鼻祖、王牌、性价比之王、祖传秘方、神效、秒杀同级、碾压竞品、吊打同行 |
| 测评独禁 | 全网测评第一、全品类最优、完爆大牌、所有同类里最好用 |
| 美妆独禁 | 医美级、院线同款、医用平替（非械字号产品） |
| 独有违规词 | 实测百分百变白、无平替、独家原料 |
| 拉踩竞品 | 明确禁止品牌互相拉踩 |
| 虚假测评 | 伪造用户体验、虚假试用（如"全闺蜜实测全好评"无凭证） |
| 诱导互动 | 一键三连、求点赞求收藏求关注、互关互赞、刷赞刷收藏 |
| 私域导流 | 微信、V、VX、手机号、二维码、私信领取、进群、资源分享 |
| 医美医疗敏感 | 祛斑、祛痘根治、美白嫩肤、医疗级、医美同款、处方药、消炎抑菌 |
| 隐形敏感 | 全网第一、博主首选、人手必备、全民种草 |

**处罚阶梯**：
轻度 → 笔记限流、隐藏曝光
中度 → 笔记下架、账号 7 天限流
重度 → 禁言、短期封号、**品牌合作权限清零**

**注意**：评论区同样在检测范围，很多人忽略。

---

### 3.4 知乎

**特点**：柔性风控，重内容轻营销，但营销导流管控持续收紧

**高频踩点**：
- 硬广导流：留联系方式、外链、"私信详聊"
- 诱导互动：关注后看答案、点赞才能查看
- 虚假测评：伪装成客观评测实为软广
- 极端化表述："所有同类里最好用"

**处罚**：内容删除、账号限制发布、答案折叠

**知乎文风特点**：长文、逻辑推理、注重可信度。
极限词在知乎尤其容易被抓（受众对夸大敏感）。

---

### 3.5 快手

**特点**：下沉市场为主，规则与抖音相近但处罚略缓

**高频踩点**：
- 绝对化用语（与抖音词库高度重合）
- 限时活动必须标明具体日期，严禁"随时结束""仅此一次""随时涨价""马上降价"
- 站外导流：展现站外联系方式、第三方平台交易
- 站外水印标识
- 烧香拜佛类内容（快手特有，迷信内容管控较严）

**低质量内容判定**：
- 无露脸直播（镜中反向露脸、无真人露脸）
- 挂机录播（长时间拍屏、播放搬运视频）
- 低成本道具代替直播（转盘代替真人演示）
- 无实景直播（绿幕代替真实环境、贴纸代替商品）

**处罚阶梯**：推荐降权 → 内容下架 → 扣分 → 禁言 → 封号

---

### 3.6 头条号（今日头条）

**特点**：信息流分发，标题党与低质内容打击较重

**高频踩点**：
- 标题党：夸张标题、内容不符
- 医疗健康类内容审核极严（头条用户健康需求高，监管重点）
- 极限词
- 虚假信息：未经证实的健康偏方
- 养生内容变相推广

**特别注意**：头条对"健康养生"类内容审核最严，
涉及疾病治疗、偏方的内容基本都会被拒。

---

### 3.7 百家号

**特点**：百度旗下，反营销最严，2026年处罚力度空前

**2026年第一季度，百家号累计处罚违规营销、导流账号超 23 万个。**

**明令禁止行为**：
- 🔴 页面展示或口播联系方式、二维码、群号、外部网址
- 🔴 引导用户私下购买、线下交易
- 🔴 内容带有明显商业化 logo、营销标识
- 🔴 出现"私信购买""咨询下单"等营销导流话术

**其他**：
- 百家号外链均为 **nofollow 属性**，无法传递网站权重
- SEO 价值低，仅可用于品牌内容占位布局
- 标题党、低质内容、拼凑内容会被降权

---

### 3.8 B站（备用）

**特点**：年轻用户，对硬广容忍度低

**高频踩点**：
- 硬广、"恰饭"未标注
- 极限词
- 站外导流
- 诱导一键三连（商业内容中）

## 四、跨平台改写检查表

同一内容跨平台发布前，必须逐平台复检：

| 检查项 | 说明 |
|---|---|
| 广告标注 | 附购买链接时须标"广告"（互联网广告办法第九条，全平台适用） |
| 极限词 | 各平台标准不同，小红书最严，抖音次之 |
| 导流词 | 各平台均有导流管控，微信生态最严 |
| 评论区 | 小红书、抖音、公众号评论区均在检测范围 |
| 封面大字 | OCR 抓取，全平台适用 |
| 直播口播 | 抖音/视频号/快手 ASR 实时监控 |

## 五、平台处罚速查

| 平台 | 初次违规 | 重复违规 | 严重违规 |
|---|---|---|---|
| 公众号/视频号 | 内容警告 | 取消流量推荐、限制发布 | 封禁账号功能 |
| 抖音 | 弹窗警告、扣信用分 | 扣保证金、下架商品、关闭购物车 | 7-30天封禁开播、永久封号 |
| 小红书 | 限流、隐藏曝光 | 笔记下架、7天限流 | 禁言、封号、品牌合作清零 |
| 知乎 | 内容删除、答案折叠 | 限制发布 | 账号限制 |
| 快手 | 推荐降权、内容下架 | 扣分、禁言 | 封号 |
| 头条号 | 推荐降权 | 内容不予通过 | 封禁账号 |
| 百家号 | 减少推荐 | 内容下架、扣信用分 | 封禁账号 |
