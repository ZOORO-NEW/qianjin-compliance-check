# 母婴 / 婴幼儿 / 儿童用品专项

**加载条件**：文案涉及奶粉、辅食、纸尿裤、童装、玩具、母婴用品、儿童食品

---

## 一、母婴类目的特殊地位

母婴用品是**监管最严、社会关注度最高**的品类之一：

1. 《广告法》第四十条：针对不满十四周岁的未成年人的商品广告
   不得含有劝诱其要求家长购买的内容，或可能引发模仿不安全行为的内容
2. 《广告法》第三十九条：不得利用中小学校、幼儿园、
   教材教辅、练习册、文具、教具、校服、校车发布广告
3. 婴幼儿食品**不得声称全部或部分替代母乳**（第二十条）
4. 母婴渠道的舆情风险：一次翻车可能导致账号永久封禁

---

## 二、婴幼儿食品（重点）

### 2.1 禁替代母乳
🔴 **禁止声称全部或部分替代母乳**（广告法第二十条）

违规表述：
- 可替代母乳、代替母乳、无需母乳、比母乳好
- 暗示可作为母乳替代品

### 2.2 不得涉及疾病预防治疗
🔴 不得增强免疫力、提高抵抗力、促进发育
🔴 不得提高智力、促进大脑发育
🔴 不得改善体质、调理肠胃（治疗义）

### 2.3 不得声称保障健康所必需
🔴 婴儿必备、宝宝必需、成长必需

### 2.4 乳制品广告特殊限制
《广告法》第二十条禁止在大众传播媒介或公共场所发布
声称全部或部分替代母乳的婴儿乳制品、饮料和其他食品广告。

## 三、婴幼儿用品

### 3.1 高危承诺
🔴 百分百无甲醛、绝对安全、零过敏
🔴 医用级、医美级（非械字号产品）
🔴 提升免疫力、促进发育（暗示）

### 3.2 合规信息方向

| 违规 | 合规 |
|---|---|
| 百分百无甲醛 | 符合 XX 标准的检测信息（附报告编号） |
| 医用级 | 符合 GB/T XXX 标准的母婴级产品（须可查证） |
| 宝宝用了不生病 | 材质柔软透气，适合新生儿日常穿着 |
| 增强免疫力 | 删除，改说材质、安全标准、使用体验 |
| 治疗红屁屁 | 日常护理建议（如勤换、保持干燥） |

### 3.3 强制信息方向
- 执行标准（GB/T 编号）
- 材质成分
- 适用年龄
- 检测报告（若引用）

---

## 四、儿童服装

### 4.1 广告法第三十九条
**不得利用中小学生的教材、教辅材料、练习册、文具、教具、
校服、校车等发布或者变相发布广告。**

> ⚠️ 注意：**校服**属于明确列举对象。
> 但这指的是利用学校统一采购渠道发布广告，
> 品牌正常宣传校服产品本身需结合场景判断。

### 4.2 幼儿服装安全承诺
🔴 绝对安全、零风险、无毒无害

合规方向：面料成分、执行标准（GB 31701 等）、
A/B/C 等级、检测信息

## 五、儿童食品与零食

### 5.1 食品底线（加载 industry-food.md）
🔴 不得涉及疾病预防治疗
🔴 不得增强免疫力、促进发育
🔴 不得声称替代母乳

### 5.2 儿童零食高危词
🔴 补脑、健脑、提高智力
🔴 增强体质、长高
🔴 护眼（治疗义）、保护视力（需谨慎）
🔴 补充营养（需谨慎，"营养"表述易越界）

### 5.3 合规方向
- 配料表与营养成分表（客观陈述）
- 口感描述（甜度、软硬度、易化程度）
- 适用年龄（按产品说明）

## 七、用户为家长的心理特殊性

家长决策时的**焦虑敏感点**是母婴违规的高发区：

| 焦虑点 | 违规利用手法 | 合规方向 |
|---|---|---|
| 怕宝宝生病 | "增强免疫力""抵抗力强" | 材质、安全标准 |
| 怕发育迟缓 | "促进大脑发育""提高智力" | 成分说明 |
| 怕过敏 | "零过敏""百分百安全" | 检测报告、试用建议 |
| 怕买到假货 | "官方授权""专柜同款" | 资质编号、购买渠道 |
| 怕营养不够 | "补充全部营养""长得快" | 营养成分表 |

> **改写原则**：把家长的焦虑**从产品功效转到安全信息**上。
> "不会生病"无法承诺，但"面料符合 A 类标准、检测报告在此"可以给出。

## 八、检查清单

- [ ] 涉及婴幼儿食品：无替代母乳宣称？
- [ ] 无疾病预防治疗功能表述？
- [ ] 无增强免疫力、促进发育等保健功能暗示？
- [ ] 无"婴儿必备""保障健康所必需"表述？
- [ ] 无绝对化安全承诺（零过敏、百分百安全）？
- [ ] 非械字号产品未宣称"医用级"？
- [ ] 无"补脑""健脑""长高"等功效宣称？
- [ ] 无针对不满十四周岁儿童的劝诱家长购买内容？
- [ ] 未利用学校教材/校服等渠道发布广告？
- [ ] 引用检测报告是否有编号可查证？
- [ ] 儿童食品营养表述是否客观（仅陈述成分表）？

## 九、真实处罚案例参考

各省市市监局民生领域广告合规提示中，
儿童用品、母婴食品相关违规普遍存在，
尤其涉及"增强免疫力""促进发育""替代母乳"三类表述。

**建议**：母婴品类在发布前，**默认按最严标准处理**。
