# 教育培训行业专项

**加载条件**：文案涉及课程、培训、考证、辅导、网校、学历提升、职业培训

## 一、核心禁令（《广告法》第二十四条）

教育、培训广告不得含有以下内容：

### 1.1 升学/通过考试/学历/证书的保证性承诺 🔴
对升学、通过考试、获得学位学历或者合格证书，
或者对教育、培训的效果作出**明示或者暗示的保证性承诺**。

**高危词**：
包过、保过、保证通过、稳过、百分百通过、
包上岸、必上岸、稳上岸、
保就业、百分百就业、包分配、
保拿证、百分百拿证、不过免费、
签约保就业、包过不过退费、
一次通过、百分百录取、免试入学拿证、
零基础也能过、月薪过万保底、
学历提升保真、通过率百分之百

> **执法指南第十一条第三项**：教育、培训广告中出现与教育、
> 培训机构或教育培训效果相关的绝对化用语，
> **不认为属于违法行为轻微**（即从重处理）。

### 1.2 暗示考试机构或命题人员参与 🔴
明示或者暗示有相关考试机构或者其工作人员、
**考试命题人员**参与教育、培训。

**高危词**：
命题组老师授课、考官亲授、内部师资、
阅卷老师辅导、官方指定培训、
与考试机构合作（无依据）、内部渠道、
押题必过（暗示泄题）、真题泄露

> 现实案例："考试命题组成员任教""阅卷老师亲自辅导"
> 均属虚假宣传套路。命题组成员严禁参与商业培训授课。

### 1.3 利用特定主体作推荐证明 🔴
利用科研单位、学术机构、**教育机构**、行业协会、
**专业人士**、**受益者**的名义或者形象作推荐、证明。

**高危词**：
学员出镜分享"零基础轻松上岸"、
一个月提分翻倍（受益者案例）、
名校老师推荐、专家一致好评、
学员感谢视频（无授权）

> 现实案例：机构安排学员出镜，分享"零基础轻松上岸"
> "一个月提分翻倍"。这些是经过筛选的成功样本，
> 放大少数亮眼成果，构成误导。

## 二、学校相关禁令

### 2.1 校园禁广告（《广告法》第三十九条）★
**不得在中小学校、幼儿园内开展广告活动**，
不得利用中小学生和幼儿的教材、教辅材料、练习册、
文具、教具、校服、校车等发布或变相发布广告（公益广告除外）。

### 2.2 未成年人相关
针对不满十四周岁的未成年人的商品或服务广告不得含有：
1. 劝诱其要求家长购买广告商品或服务
2. 可能引发其模仿不安全行为

## 三、其他行业条款联动

### 3.1 金融属性
若课程涉及"学完能接单月入过万""学完就能创业赚钱"：

→ 加载 industry-investment.md
→ 触发广告法第二十五条（招商投资回报预期）

🔴 禁止：学完月入过万、保底收入、保证接单、
学完就能赚钱、高薪就业保障、无门槛赚钱

### 3.2 学历提升
若涉及学历/学位承诺：
→ 🔴 绝对禁止"保过""百分百拿证""不用考试直接拿"
→ 学历提升广告须真实、可查、具备资质

## 四、合规替换示例

| 违规写法 | 合规写法 |
|---|---|
| 包过，不过免费 | 提供系统课程 + 模拟题库，帮助你熟悉题型 |
| 零基础必上岸 | 按章节设计的课程，进度可自己把控 |
| 签约包就业 | 结业后可查看学员作品集（须有授权） |
| 命题老师亲自授课 | 教研团队根据考纲整理的课程内容 |
| 内部师资押题必过 | 历年真题解析，帮助理解出题思路 |
| 学完月入过万 | 课程涵盖 XX 技能，接单渠道与报价可参考平台数据 |
| 过目不忘 | 记忆曲线课程设计，配合复习计划 |

> **注意**：改写不是把"包过"换成"基本都能过"——
> "基本"仍是暗示性承诺。要改成描述**课程提供什么**，
> 而不是**结果能否保证**。

## 五、高频踩坑场景

### 场景1：AI 工具培训课程（用户潜在场景）
若推广"AI 变现课"：
- 🔴 "学完月入 5 万" → 违反第二十五条
- 🔴 "保证接到单" → 投资回报承诺
- 🔴 "轻松变现" → 暗示虚假低门槛收益

**合规方向**：
强调课程内容（提示词模板、工作流搭建、实战案例），
案例呈现须标明"以下为学员作品，实际效果因人而异"。

### 场景2：国学/传统文化课程
- 内容本身不违规
- 但"学完就能改变命运""7 天开悟"→ 迷信 + 教育效果承诺
- "大师亲授"→ 需真实资质，且不得暗示权威

### 场景3：考证班
- 须核查办学资质
- 不得承诺通过
- 不得暗示命题人员参与

## 六、检查清单

- [ ] 有办学资质？
- [ ] 无升学/考试/学历/证书的保证性承诺？
- [ ] 无"基本能过""99% 通过率"等暗示承诺？
- [ ] 无暗示考试机构或命题人员参与？
- [ ] 无"权威专家推荐""学员受益案例"未经授权？
- [ ] 无"月入过万""保证接单"等投资回报承诺？
- [ ] 未在中小学校/幼儿园投放？
- [ ] 针对未成年人：无劝诱家长购买内容？
- [ ] 课程效果表述是否已改为"提供什么"而非"保证什么"？
