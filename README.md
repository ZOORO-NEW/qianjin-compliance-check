# qianjin-compliance-check · 文案合规检查引擎

> 写完先过一遍这个 skill，再发出去。

自媒体与商业推广文案的全域合规预检技能。融合中国广告法体系与八大平台发布规则，
输出**分级风险清单 + 原文定位 + 可直接发布的合规改写稿**。

---

## 为什么需要它

自媒体发稿的真实风险不在"会不会被删"，而在**你不知道它已经违规了**：

- 平台审核用 OCR + ASR + 语义模型，谐音、拆分字、符号替代全部可识别
- 同一句话在不同平台判定不同（小红书最严，百家号反营销）
- 特殊行业（食品、化妆品、母婴、医疗）有独立的高危红线
- 广告法不是"极限词表"，有大量**可放行情形**和**从重情形**，机械替换会毁掉文案

本 skill 的目标不是把你吓住，而是**告诉你哪句能发、哪句怎么改**。

---

## 核心特点

### 1. 判定语境，不只匹配词

同一个"最"字，判定结果完全不同：

| 场景 | 判定 |
|---|---|
| 「这是我用过最好用的」 | 主观评价，通常不违规 |
| 「全网最好用，销量第一」 | 指向商品性能 + 不可考证 → 高危 |
| 「国家级期刊《XX》刊载」 | 有依据，可放行 |

依据《广告绝对化用语执法指南》第五、六条，技能内置了**可放行情形对照表**，
避免"一刀切"式误报。

### 2. 改写给"怎么用"，不是"别碰"

改写输出永远是可直接复制的成句，且保留说服力：

```
原：全网最好用的 AI 画图工具
改：我试过七八个同类工具，目前主力用这个。
    生成一张 1024×1024 的图大概 8 秒，细节还原比另外两个更稳，
    人物手指不容易出错。缺点是复杂构图还得手动调几次。
```

注意改写稿**加了缺点**——这既提升可信度，又完全合规。

## 使用方式

### 场景 A：审前预检（主力）

```
[文案内容]

目标平台：公众号
类型：普通自媒体干货
帮我做发稿前合规预检，有问题直接标红给我
```

三种反馈模式：

| 模式 | 输出 |
|---|---|
| 标红模式 | 只标出问题位置和建议，不动原文 |
| 直接改模式 | 给出改好的完整稿，原文对照 |
| 只查高危模式 | 只报 🔴，快速过一遍 |

### 场景 B：只查词

```
帮我查一下这段文案有没有违规词
```

### 场景 C：建稿期拦截（最高效）

在写作阶段就注入约束，不等写完再改：

```
这篇文案涉及[行业]，写作时就按合规要求来：
不要用极限词，功效表述不得超出[XX]范围。
```

## 输出示例

```markdown
## 合规检查报告

**结论**：🟡 中危（1 处需立刻改）

### 场景判定
- 商业广告：否（无购买链接，不强制标"广告"）
- 目标平台：公众号

### 🟡 中危项

**1. [免费模型段] 原文片段**
> 「能比较顺地白嫖到」

- 风险类型：诱导性表述
- 依据：《广告法》第二十五条（投资回报预期）
- 判定：单看"免费"不违法，但"白嫖"属诱导性口语
- 改写建议：「能比较顺地用上」

### ✅ 合规亮点
- 如实告知产品限制（"国内网络用不了"）
- 劝退式表达，平台最吃这个
```

## 六步执行流程

1. **判定场景属性** — 是否商业广告 / 主体身份 / 产品资质 / 目标平台
2. **法律层扫描** — 结构性违规优先（可识别性、强制标注、引证出处）
3. **词库层扫描** — 14 章词库 + 变体识别
4. **行业层加严** — 加载对应行业包
5. **平台层校准** — 加载目标平台加严项
6. **输出报告** — 分级 + 定位 + 改写稿

## 边界声明

本技能是**发稿前合规预检工具**，不是法律意见书。

- 不提供"如何规避审核"的方案
- 不替代专业法务审查
- 涉及重大金额或专业医疗问题时，建议咨询专业法务
- 法规与平台规则会变，重要内容建议核对官方最新表述
