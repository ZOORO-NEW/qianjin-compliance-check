# 医疗 / 药品 / 医疗器械 / 医美 / 消毒产品 专项

**加载条件**：文案涉及医疗机构、医疗服务、药品、医疗器械、医美、消毒产品

---

## 一、医疗服务广告（M1）

### 1.1 前置审查（最高优先级）

**未取得《医疗广告审查证明》的，不得发布医疗广告。**

自媒体探店、就医体验分享，涉及以下内容即构成医疗广告：
- 介绍医院/诊所/门诊的名称、地址、联系方式
- 描述诊疗项目、诊疗方法
- 介绍医疗服务价格、优惠
- 推荐特定医疗机构

> ⚠️ **不可发布的医疗内容**：非医疗机构发布或介绍非自己机构的内容，往往构成变相发布。

### 1.2 禁止内容（《广告法》第十六条 + 第三项）

🔴 绝对禁止：

| 内容 | 说明 |
|---|---|
| 治愈率、有效率 | 说明治愈率或者有效率 |
| 疗效断言或保证 | 表示功效、安全性的断言或者保证 |
| 与其他医疗机构比较 | 与其他药品、医疗器械的功效安全性或其他医疗机构比较 |
| 利用广告代言人推荐证明 | 包括患者形象、体验者名义 |
| 专家、医师、患者名义形象 | 医疗机构名称地址联系方式诊疗项目诊疗方法 |
| 神医神药 | 借健康科普形式变相发布 |

🔴 常见高危词：治愈、根治、疗效显著、痊愈率、成功率、
神医、名医、祖传秘方、专治、包好、特效、奇效、
一次见效、当天见效、立竿见影

### 1.3 医疗美容广告（M4）

🔴 禁止：
- 制造容貌焦虑（"不做就完了""25岁必须做"）
- 夸大治疗功效
- 对治疗安全作保证性承诺（"零风险""绝对安全""不出血"）
- 未取得《医疗广告审查证明》发布

🔴 化妆品不得宣称医美级效果：
"医美级""院线同款""医用敷料平替""水光针级"
→ 违反《化妆品监督管理条例》第四十三条

### 1.4 变相发布禁令（《广告法》第十九条 + 互联网广告办法第八条）

**不得以介绍健康、养生知识等形式，变相发布医疗广告。**

🔴 典型违规：
- "医生都不愿意告诉你的养生秘诀" + 医院名称/联系方式
- "这样喝能治 XX 病" + 挂某医疗机构链接
- 科普视频中口播医院地址

**互联网广告办法第八条特别规定**：介绍健康、养生知识的，
**不得在同一页面或者同时出现**相关医疗、药品、医疗器械、
保健食品、特医食品的商品经营者或服务提供者的地址、联系方式、
购物链接等内容。

### 1.5 合规写法示例

| 违规写法 | 合规写法 |
|---|---|
| 某医院治疗 XX 病，治愈率 95% | 介绍该医院具备的诊疗资质（须有广告审查证明） |
| 专家推荐 | 医院官方发布的科普内容，无个人推荐 |
| 我们的疗法能根治 XX | 删除疗效表述，仅介绍机构资质与服务范围 |
| 神奇疗法，三天见效 | 删除 |

## 二、药品广告（M2）

### 2.1 禁播药品（绝对禁止）

🔴 麻醉药品、精神药品、医疗用毒性药品、放射性药品等特殊药品，
药品类易制毒化学品，戒毒治疗的药品、医疗器械和治疗方法，
**一律不得作广告**。

### 2.2 处方药

处方药**只能在国务院卫生行政部门和药品监督管理部门共同指定的
医学、药学专业刊物上作广告**。

→ 抖音、公众号、小红书、知乎等**全部属于禁止投放渠道**。

### 2.3 非处方药（OTC）可在大众媒介投放，但须标注

- **非处方药标识（OTC）**
- **"请按药品说明书或者在药师指导下购买和使用"**

### 2.4 药品广告禁止内容

依据《广告法》第十六条 + 三品一械审查办法第十一条：

🔴 表示功效、安全性的断言或者保证
🔴 说明治愈率或者有效率
🔴 与其他药品、医疗器械的功效和安全性比较
🔴 利用广告代言人作推荐、证明
🔴 使用科研单位、学术机构、行业协会、专家、学者、医师、药师、患者名义或形象作推荐证明
🔴 违反科学规律明示暗示可治疗所有疾病、适应所有症状、适应所有人群
🔴 "安全""安全无毒副作用""毒副作用小""天然所以安全"
🔴 "热销、抢购、试用""家庭必备、免费治疗、免费赠送"
🔴 "评比、排序、推荐、指定、选用、获奖"
🔴 "无效退款、保险公司保险"
🔴 怂恿任意、过量使用

### 2.5 强制标注

- **广告批准文号**（须显著标明）
- **禁忌、不良反应**（须与说明书一致）
- 视频广告中上述内容**须持续显示**

> 药品广告内容不得与批准的说明书不一致。

### 2.6 高危词

根治、治愈、疗效、药效、特效、见效、无副作用、
抗肿瘤、降三高、抗癌、杀死病毒、包治百病、
祖传秘方、宫廷秘方、名医推荐、康复、
正常人体细胞再生、修复受损器官

## 三、医疗器械广告（M3）

### 3.1 前置审查
须取得**医疗器械广告审查批准文号**，未经审查不得发布。

### 3.2 禁止内容

同药品大部分禁止项，另加：

🔴 **禁止说明治愈率、有效率**（比药品更严）

### 3.3 强制标注

🔴 **推荐给个人自用的医疗器械**：必须显著标明
**"请仔细阅读产品说明书或者在医务人员的指导下购买和使用"**

🔴 **注册证书中有禁忌内容、注意事项的**：必须显著标明
**"禁忌内容或者注意事项详见说明书"**

🔴 广告批准文号

> 视频广告中上述内容须持续显示。

### 3.4 家用医疗器械高危

普通消费者可自行购买使用的家用器械类（如血压计、血糖仪、制氧机、
按摩仪、颈椎治疗仪、护眼仪），是最容易违规的品类：

🔴 高危宣称：
- 治疗颈椎病、腰间盘突出、糖尿病、高血压等具体疾病
- 治愈率、有效率
- "替代药物""不用吃药"
- 磁疗、频谱、远红外等物理疗法暗示治疗疾病
- "康复""恢复""降度数"

> **特别提醒**：制氧机、按摩仪、治疗仪类目，自媒体带货
> 宣称疾病治疗功能是监管重点，也是行政处罚高发区。

### 3.5 合规写法

| 违规 | 合规 |
|---|---|
| 这款按摩仪能治颈椎病 | 这款按摩仪提供肩颈部位放松功能（须与说明书一致） |
| 降血糖效果显著 | 删除功效表述，仅介绍产品功能与参数 |
| 家用理疗仪治疗腰间盘突出 | 无医疗器械注册证的，不得作医疗器械宣传 |

## 四、消毒产品

### 4.1 定义
消毒产品不属于药品，不具备疾病治疗功能。

### 4.2 禁止内容

🔴 **不得明示或暗示具有疾病治疗作用**

🔴 禁止：杀菌率、抑菌率等作为疾病治疗宣称
🔴 禁止：抗病毒、预防流感、治疗脚气、治妇科病
🔴 禁止：WHO/国际组织认证（除非真实可查且属于消毒产品资质）

### 4.3 典型案例（处罚）

> 杭州岳纳姗网络科技有限公司：公众号文章宣称某消毒液
> "世界卫生组织认证""可消灭残留的新型冠状病毒""杀菌率高达99.9%"
> → 无法提供依据，罚款1万元，构成虚假广告

### 4.4 合规写法

| 违规 | 合规 |
|---|---|
| 杀菌率 99.9%，可消灭新冠病毒 | 该产品符合 GB/T 相关标准（须有卫生安全评价报告） |
| 预防流感 | 该产品用于物体表面消毒（非人体使用） |
| 治疗脚气 | 脚气属疾病，消毒产品不可宣称 |

> ⚠️ 注意：即便是普通日化品（洗手液），也不得宣称"抗菌"
> 用于人体疾病语境。日常洗手液标注"抑菌"须有卫生安全评价。

## 六、通用医疗词库速查

🔴 **疾病治疗功能（所有非医疗广告禁用）**
治疗、治愈、根治、痊愈、疗效、药到病除、消炎、杀菌、
抗菌、抑菌、除菌、抗病毒、防癌、抗癌、抑制肿瘤、
杀死癌细胞、降血糖、降血压、降血脂、降三高、
疏通血管、排毒、养生治本、调理病症

🔴 **药品医疗用语（食品化妆品日用品全部禁用）**
处方、非处方、临床验证、治疗方案、适应症、
疗程、服用剂量、注射、输液、外用内服

🔴 **虚假医疗背书**
祖传秘方、宫廷秘方、神医、名医、专家一致好评、
临床验证、国家认证疗法、攻克 XX 病

## 七、检查清单

### 医疗/药械内容发稿前逐项确认

- [ ] 有《医疗广告审查证明》/ 广告审查批准文号？
- [ ] 无治愈率、有效率表述？
- [ ] 无疗效断言或安全保证？
- [ ] 无与其他机构/药品比较？
- [ ] 无广告代言人、患者、专家名义推荐？
- [ ] 未在处方药禁止渠道投放？
- [ ] 强制标注齐全（批准文号/不良反应/禁忌/说明书提示语）？
- [ ] 非医疗机构未变相发布医疗广告？
- [ ] 养生科普内容未同页出现医疗机构地址电话购物链接？
- [ ] 视频广告中强制标注内容是否持续显示？
