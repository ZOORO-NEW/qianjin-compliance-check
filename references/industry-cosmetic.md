# 化妆品专项（普通化妆品 + 特殊化妆品）

**加载条件**：文案涉及护肤、彩妆、洗护、香水、防晒、染发烫发等

---

## 一、产品分类：先判断是普通还是特殊

### 特殊化妆品（须注册，功效受限）
染发剂、烫发剂、祛斑美白产品、防晒产品、防脱发产品、
以及**宣称新功效**的化妆品。

注册证编号格式：
- 国产：**国妆特字**+年份+序号
- 进口：**国妆特进字**+年份+序号
- 中国台湾、香港、澳门：**国妆特制字**+年份+序号

### 普通化妆品（须备案）
除特殊化妆品外的化妆品。功效只能按备案功效宣称。

备案编号格式：
- 国产：省简称 + **G妆网备字** + 年份 + 序号
- 进口：**国妆网备进字**+省份简称+年份+序号

> ⚠️ **这是最常见的踩坑点**：很多博主不知道"防脱发""祛痘"
> 属于特殊化妆品功效，普通洗发水、普通面霜宣称这些直接违法。

## 二、核心禁令（条例第四十三条 + 标签办法第十九条）

### 2.1 广告层（条例第四十三条）

化妆品广告：
- 🔴 **不得明示或暗示产品具有医疗作用**
- 🔴 不得含有虚假或引人误解的内容
- 🔴 不得欺骗、误导消费者

### 2.2 标签层（标签办法第十九条，十二项禁止）

🔴 1. 使用医疗术语、医学名人姓名、描述医疗作用效果的词语或已批准的药品名，明示或暗示医疗作用
🔴 2. 使用虚假、夸大、绝对化的词语进行虚假或引人误解地描述
🔴 3. 利用商标、图案、字体颜色大小、色差、**谐音**或暗示性文字、字母、汉语拼音、数字、符号等方式暗示医疗作用或虚假宣称
🔴 4. 使用尚未被科学界广泛接受的术语、机理编造概念误导
🔴 5. 通过编造虚假信息、**贬低其他合法产品**等方式误导
🔴 6. 使用虚构、伪造或无法验证的科研成果、统计资料、调查结果、文摘、引用语
🔴 7. 通过宣称所用原料的功能暗示产品实际不具有或不允许宣称的功效
🔴 8. 使用未经相关行业主管部门确认的标识、奖励等进行安全及功效相关宣称
🔴 9. 利用国家机关、事业单位、医疗机构、公益性机构及其工作人员、聘任的专家的名义形象作证明推荐
🔴 10. **表示功效、安全性的断言或者保证**
🔴 11. 标注庸俗、封建迷信或其他违反社会公序良俗的内容
🔴 12. 法律行政法规和强制性国标禁止标注的其他内容

> **注意第3项**：谐音、拼音、符号暗示是明确的违法手段。
> "CUCUMBER 提取物焕白"（美白的谐音暗示）也可能违规。

## 三、高危词库

### 3.1 医疗暗示类（全部禁用）🔴

消炎、杀菌、抑菌、除菌、抗菌、消毒、
修复受损肌理、修复屏障（治疗义）、治愈、
药妆、医学护肤品、医美级、院线同款、
医用敷料平替、械字号面膜、皮肤科医生推荐、
溶解死细胞、溶脂、燃烧脂肪、
激素脸修复（暗示医疗）、皮炎修复（暗示医疗）、
祛痘（治疗义）、祛斑（治疗义）、除螨（治疗义）

### 3.2 绝对化夸大类 🔴
最有效、最佳、顶级、极致、永久、天花板、
绝对、第一、唯一、100%有效、无效退款、
彻底清除、一次见效、立刻变白

### 3.3 功效超范围类（须核对备案功效）🔴

**普通化妆品不得宣称：**
- 祛斑美白
- 防晒（须特殊化妆品）
- 防脱发
- 防脱屑
- 去除鸡皮
- 修复屏障（治疗义）
- 收缩毛孔（部分严格）
- 抗皱（须按备案）

**普通化妆品可以宣称（按备案）：**
清洁、保湿、滋养、润养、舒缓（一般表述）、
清洁（须有对应备案）、发用产品的基础护理

### 3.4 权威冒充类 🔴
医研共创、皮肤科医院合作（无证明）、
国家机构认证（虚构）、Dr 推荐（虚构）、
零过敏（绝对化）、婴儿可用（须安全评估依据）、
孕妇可用（须安全评估依据）、纯天然无添加（须以标签为准）

### 3.5 医疗美容类表述 🔴
水光针、注射、填充、玻尿酸（作为产品功效）、
热玛吉、超声炮（暗示医疗）、医疗级、
械字号、医用、院线（无依据）

### 3.6 虚假对比类 🔴
七天祛斑、28天白一个度（无法证明）、
完全消灭（痘/斑/皱纹）、
对比图 P 图、虚假的用前用后（违标签办法第六项）

## 四、特殊化妆品额外要求

### 染发剂
- 须有特殊化妆品注册证
- 标签须标注注册证编号
- 须标注安全警示（使用前做皮肤敏感试验等）
- **不得暗示治疗脱发**

### 烫发剂
- 同上

### 祛斑美白产品
- 须特殊化妆品注册证
- 须标注注册证编号
- 宣传须按核准功效表述

### 防晒产品
- 须特殊化妆品注册证
- 须标注 SPF/PA 值（须与注册一致）
- **不得**宣称"绝对防晒""100%防晒"

### 防脱发产品
- 须特殊化妆品注册证
- 普通洗发水宣称"防脱发"直接违法
- 不得宣称"治疗脱发"

## 五、强制标注（条例第三十六条）

化妆品标签应标注：
1. 产品名称、**特殊化妆品注册证编号**
2. 注册人、备案人、受托生产企业名称、地址
3. 化妆品生产许可证编号
4. 产品执行的标准编号
5. 全成分
6. 净含量
7. 使用期限、使用方法及必要安全警示
8. 法律行政法规和国标规定应当标注的其他内容

小规格（净含量 ≤15g 或 15mL）：
仅需标注产品中文名称、特殊化妆品注册证书编号、
注册人或备案人名称、净含量、使用期限。

## 六、合规替换示例表

| 违规写法 | 依据 | 合规写法 |
|---|---|---|
| 100% 美白 | 标签办法第十九条第二项 | 使用后肤感提亮，我个人感受明显（须有备案支持美白则为特殊化妆品） |
| 祛痘神器 | 医疗暗示 | 适合日常护理，配方温和 |
| 医美级平替 | 医疗暗示 | 日常护理足够用 |
| 抗炎修复 | 医疗用语 | 舒缓维稳 |
| 敏感肌救星 | 暗示医疗 | 配方相对温和，建议先做局部试用 |
| 除螨率 99% | 功效虚标 | 洁净力表现不错（以实际检测为准） |
| 某 dermatologist 推荐 | 专家背书 | 品牌方公开信息（如有） |
| 一周淡斑 | 超备案功效 | 按备案功效表述 |
| 医用敷料同款 | 医疗器械暗示 | 敷料类产品的实际备案信息 |
| 无添加防腐剂 | 需以标签为准 | 配料表信息（以产品实际标签为准） |
| 婴儿可用 | 安全断言 | 建议首次使用先在耳后测试 |
| 快速成膜不黏腻 | 性能表述 | 成膜速度与肤感为使用体验描述 |

## 七、化妆品类目高危检查清单

### 发稿前逐项确认

- [ ] 判断清楚是普通化妆品还是特殊化妆品？
- [ ] 特殊化妆品：有特殊化妆品注册证编号？功效按核准表述？
- [ ] 普通化妆品：所有功效均在备案范围内？
- [ ] 无医疗术语、无治疗暗示？
- [ ] 无绝对化用语？
- [ ] 无功效断言或安全保证？
- [ ] 未通过原料/谐音/符号暗示医疗作用？
- [ ] 无虚构科研成果或检测数据？
- [ ] 未贬低其他产品？
- [ ] 无"医美级""院线同款"等混淆表述？
- [ ] 无未经确认的标识、奖励用于功效宣称？
- [ ] 未使用"零过敏""纯天然无添加"等绝对化表述？
- [ ] 敏感人群表述是否谨慎（婴幼儿/孕妇须有安全依据）？
