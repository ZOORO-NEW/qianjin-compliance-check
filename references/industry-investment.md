# 招商加盟 / 投资回报 / 酒类 专项

**加载条件**：文案涉及加盟、招商、代理、合伙、投资、返利，以及酒类推广

---

## 一、招商加盟 / 投资回报类（M12）

### 1.1 核心条款（《广告法》第二十五条）

招商等有投资回报预期的商品或者服务广告，
**应当对可能存在的风险以及风险责任承担有合理提示或者警示**，
并不得含有：

#### 禁止一：保证性承诺
🔴 对未来效果、收益或者与其相关的情况作出保证性承诺
🔴 明示或者暗示**保本、无风险或者保收益**（国家另有规定的除外）

#### 禁止二：特定主体背书
🔴 利用**学术机构、行业协会、专业人士、受益者**的名义或形象作推荐、证明

### 1.2 强制要求
**必须包含风险提示与风险责任承担警示。**

> ⚠️ 很多招商文案只讲收益不讲风险，这是第二十五条的核心违规点。
> 只写"月入 3 万"不写"投资有风险，可能亏损"，即构成违规。

### 1.3 执法尺度（绝对化用语执法指南第十一条）
招商等有投资回报预期的商品广告中出现与**投资收益率、投资安全性**
相关的绝对化用语的，**不认为属于违法行为轻微或社会危害性较小**
（即从重处理，不适用免罚条款）。

## 二、典型处罚案例

### 案例1：茶饮加盟招商广告
> 杭州奇异鸟饮品科技连锁有限公司
> 在多个加盟网站发布招商广告，含"**投资小、利润高、回报快**"
> 及"方先生"投资成功案例等内容，宣称无风险或无风险责任承担提示
> → 违反《广告法》第二十五条
> → 罚款 **18400 元**

### 案例2：虚构荣誉与合作伙伴
> 杭州福腾电子商务有限公司
> 网页展示"电商行业领军品牌""中国消费者可信赖企业"等 8 张荣誉证书，
> 宣称合作伙伴有"新浪、华为、中兴、CCTV 证券资讯、淘宝、拼多多"等
> → 经查荣誉牌匾来自互联网，合作伙伴基本虚构
> → 构成《广告法》第二十八条虚假广告
> → 罚款 **12000 元**

### 案例3：量能足疗 + 承诺房产升值
> 涉及"升值或投资回报承诺"，最高被罚 60 万元

## 三、高危词库

### 3.1 保本保收益 🔴
保本、保收益、保底收益、稳赚、无风险、零风险、
稳赚不赔、投资小利润高、回报快、高回报、
躺赚、被动收入、包赚、翻身、
财富自由、快速致富、月入十万、
日入过千、轻松月入、零基础赚钱、
一本万利、薄利多销、回本快

### 3.2 虚假背书 🔴
行业第一品牌、龙头品牌、上市公司背书、
央视推荐（虚构）、知名机构战略合作（虚构）、
"投资成功案例"（未经授权或筛选）、
创始人 IP 背书、明星代言（无授权）、
加入 XX 品牌月入 X 万（虚假）

### 3.3 风险缺失 🔴
"稳赚不赔"类内容**必须**配风险提示，
否则即使收益表述合法，也可能构成"未作风险提示"违规。

> **合规做法**：写收益的同时必须写风险，二者不可分割。

## 四、酒类（M13）

### 4.1 核心条款（《广告法》第二十三条）★
酒类广告不得含有：

🔴 1. **诱导、怂恿饮酒或者宣传无节制饮酒**
🔴 2. **出现饮酒的动作**
🔴 3. **表现驾驶车、船、飞机等活动**
🔴 4. **明示或暗示饮酒有消除紧张和焦虑、增加体力等功效**

### 4.2 场景理解

| 场景 | 是否违规 |
|---|---|
| 展示举起酒杯碰杯的动作 | 🔴 违规（出现饮酒动作） |
| 展示开车同时饮酒 | 🔴 违规（驾驶活动） |
| "喝一杯缓解压力" | 🔴 违规（暗示饮酒功效） |
| "越喝越有" | 🔴 违规（诱导无节制饮酒） |
| 静态展示酒瓶产品图 | ✅ 合规 |
| 介绍酒的工艺、产地、口感 | ✅ 合规 |
| "酒桌必备""不喝不算男人" | 🔴 违规（诱导） |
| 婚宴场景展示酒（无饮酒动作） | ⚠️ 需谨慎 |

### 4.3 诱导类表述
🔴 不喝不是男人、不喝不懂酒、
酒桌文化、酒逢知己千杯少、
喝出气质、喝出自信、
应酬少不了、人情世故离不开、
无酒不欢

### 4.4 功效类表述
🔴 活血、养生、舒筋活络、
增强体力、消除疲劳、缓解焦虑、
助眠、安神

> **注意**：文案中描述"酒的历史渊源""酿造工艺""酒文化"
> 属正常内容创作，不受第二十三条限制。
> 关键判断是：**是否在推销商品且宣称饮用功效**。

## 五、房地产（备用，M16）

若涉及房地产推广，加载本条：

### 禁止内容（《广告法》第二十六条）
🔴 升值或者投资回报的承诺
🔴 以项目到达某一具体参照物的所需时间表示项目位置
🔴 违反国家有关价格管理的规定
🔴 对规划或建设中的交通、商业、文化教育设施以及其他市政条件作误导宣传
🔴 不得含有广告主能够为入住者办理户口、就业、升学等事项的承诺

### 要求
房源信息应当真实，面积应当表明为**建筑面积**或**套内建筑面积**。

## 六、近视防控类（备用，M17）

若涉及近视防控产品（部分省市单独强调）：

### 禁用表述
🔴 康复、恢复、摘镜、降低度数、近视治愈、
近视克星、度数修复、
快速提升视力、逆转近视、摘掉眼镜

### 禁止行为
🔴 出现降低近视度数的画面、视频等误导消费者
🔴 伪造统计数据或科学实验数据宣传近视防控效果

> 注意：国家卫健委明确"近视可逆"是伪科学，
> 任何宣称逆转、修复度数的表述均属违规。

## 七、合规替换示例

| 违规 | 合规 |
|---|---|
| 投资小利润高回报快 | 门店前期投入明细可参考我们的成本清单（附风险提示） |
| 稳赚不赔 | 项目存在经营风险，投资需谨慎评估自身承受能力 |
| 月入 3 万 | 部分门店经营者反馈月流水区间供参考（须授权且标注因人而异） |
| 加入 XX 品牌年入百万 | 收益与经营情况相关，建议先实地考察 |
| 喝一杯缓解压力 | 静态展示产品，建议适量饮酒 |
| 越喝越有 | 介绍酒的工艺与口感 |
| 近视恢复、降低度数 | 户外活动有助于缓解用眼疲劳（不作疗效表述） |

## 八、检查清单

### 招商加盟类

- [ ] 是否包含风险提示与风险责任承担警示？
- [ ] 无保本、无风险、保收益表述？
- [ ] 无保证性收益承诺？
- [ ] 收益数据是否有真实依据？是否说明因人而异？
- [ ] "投资成功案例"是否有授权？是否为筛选后样本并已说明？
- [ ] 荣誉、合作方信息是否真实可查？
- [ ] 绝对化用语是否已清理（此领域从重处理）？

### 酒类

- [ ] 无饮酒动作画面描述？
- [ ] 无驾驶车船飞机场景？
- [ ] 无饮酒功效宣称（缓解压力、增强体力）？
- [ ] 无诱导无节制饮酒表述？
- [ ] 无"不喝不是男人""无酒不欢"等诱导？

### 房地产

- [ ] 面积标明为建筑面积或套内建筑面积？
- [ ] 无升值或投资回报承诺？
- [ ] 无"10分钟到市中心"类位置表述？
- [ ] 无户口、就业、升学承诺？
- [ ] 规划中设施未作误导宣传？
